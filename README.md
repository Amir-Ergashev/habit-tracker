# Персональный фитнес-ассистент

Приложение для ведения дневника тренировок, отслеживания прогресса и нагрузок,
с модулем ИИ-рекомендаций.

## Назначение
Пользователь ведёт дневник тренировок: записывает выполненные упражнения, вес,
количество подходов и повторений. Приложение показывает прогресс по времени
и в будущем сможет давать рекомендации на основе истории тренировок.

## Пользовательские сценарии
1. Пользователь регистрируется и входит в аккаунт.
2. Создаёт новую тренировку и добавляет в неё упражнения (вес, подходы, повторения).
3. Просматривает историю тренировок.
4. Смотрит прогресс по конкретному упражнению (как менялся рабочий вес со временем).
5. (В следующих лабораторных) получает рекомендации от ИИ-модуля на основе истории.

## Экраны
- Вход / регистрация
- Дневник тренировок (список)
- Создание новой тренировки
- Прогресс по упражнению / тренировке

## Запуск
npm install
npm run dev

Приложение будет доступно на http://localhost:5173/
