# Habit Tracker

Приложение для отслеживания личных привычек.

## Назначение
Пользователь создаёт привычки, которые хочет выработать (например, читать, делать зарядку),
и отмечает их выполнение каждый день, чтобы видеть прогресс и серию дней подряд.

## Пользовательские сценарии
1. Пользователь регистрируется и входит в аккаунт.
2. Создаёт новую привычку (название, периодичность).
3. Каждый день отмечает выполнение привычки.
4. Смотрит статистику и серию дней по привычке.

## Экраны
- Вход / регистрация
- Список привычек
- Создание новой привычки
- Статистика по привычке
